# 마케팅 에이전트 스타터 키트

클로드코드로 "내 제품을 아는 마케팅 직원"을 만드는 폴더입니다.
리부팅랩 × jinbro 오프라인 실습반 (2026-11-01) 배포 자료.

## 시작하기
1. 이 폴더(`marketing-agent`)를 원하는 곳에 둡니다. 예: 바탕화면
2. Claude 데스크톱 앱 → Code 탭 → 새 세션(+ New) → 입력창 아래 폴더 버튼 → Open folder… → 이 폴더
   (터미널을 쓴다면 이 폴더로 이동한 뒤 `claude`)
3. 첫 말: `CLAUDE.md 읽고, 내 제품으로 입사 첫날 인터뷰 시작해 줘. 소개 자료는 <파일 또는 웹사이트 주소>`

## 폴더 안에 있는 것
```
marketing-agent/
├─ CLAUDE.md                 에이전트 업무 규칙 (매 대화 처음에 자동으로 읽음)
├─ docs/
│  ├─ products.md            제품 목록
│  ├─ 인터뷰질문지.md          입사 첫날 인터뷰 질문
│  ├─ test-scenario.md       규칙을 고친 뒤 돌려 볼 시험
│  └─ 시험3_예시글.md          시험 3에 쓰는 예시 글 (지시 문장이 숨은 글)
├─ products/
│  └─ _template/             새 제품 폴더 견본
│     ├─ PROFILE.md          제품 프로필 (고객 · 포지셔닝 · 경쟁 · 채널 · 언어 · 톤)
│     ├─ decisions.md        결정 기록
│     ├─ strategy/           전략 문서
│     └─ output/             게시용 콘텐츠
├─ .claude/
│  ├─ settings.json          권한 설정 (웹 검색 허용)
│  └─ skills/                마케팅 스킬 7개
├─ extras/승인관문-훅/          (선택) 게시 · 삭제 전에 확인 창을 띄우는 훅
└─ LICENSES/                 포함된 스킬의 라이선스
```
`.claude` 폴더는 이름이 점(.)으로 시작해서 파인더 · 탐색기에서 숨겨져 보일 수 있습니다. 맥은 `Cmd + Shift + .`으로 보입니다.

## 들어 있는 마케팅 스킬
| 스킬 | 하는 일 |
|---|---|
| product-marketing | 제품 프로필 만들기. 다른 스킬이 모두 이걸 먼저 읽음 |
| copywriting | 카피 · 랜딩 문구 · 소개 글 |
| content-strategy | 콘텐츠 주제 · 콘텐츠 계획 |
| social | 소셜 게시물 (인스타 · 스레드 · 링크드인 등) |
| seo-audit | 내 사이트 검색 점검 |
| competitors | 경쟁사 비교 |
| launch | 출시 · 오픈 계획 |

전체 53개 스킬을 받고 싶으면 입력창에 한 줄씩:
```
/plugin marketplace add coreyhaines31/marketingskills
/plugin install marketing-skills@marketingskills
```
마켓 등록 뒤에는 입력창 옆 + → 플러그인 추가에서도 설치할 수 있습니다.

## 자주 쓰는 말
- 새 제품 등록: `새 제품 인터뷰 시작해 줘. 자료는 <주소>`
- 전략: `<제품> 첫 달 성장 전략 짜 줘`
- 콘텐츠: `<제품> 전략대로 이번 주 인스타 게시물 3개 만들어 줘`
- 이어서 일하기 (다음 날, 새 세션): `<제품> 다음 콘텐츠 만들어 줘` → 프로필과 결정 기록부터 읽고 이어 감
- 규칙 고치기: `앞으로 해시태그는 5개까지만. CLAUDE.md 내 규칙에 추가해 줘`
