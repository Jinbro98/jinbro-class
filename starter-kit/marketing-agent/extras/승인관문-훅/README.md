# 승인 관문 훅 (선택)

CLAUDE.md의 "승인 관문"은 클로드가 읽고 지키는 약속이다. 훅은 클로드가 깜빡해도 프로그램이 대신 막는 안전장치다.
강의에서는 강사가 시연만 한다. 써 보고 싶은 분만 아래처럼 켠다. 파이썬 3가 설치되어 있어야 한다.

## 켜는 법
1. `gate_check.py`를 `.claude/hooks/gate_check.py`로 복사한다 (`.claude/hooks/` 폴더가 없으면 만든다)
2. `settings-예시.json`의 `hooks` 부분을 `.claude/settings.json`에 합친다
   (클로드에게 "extras/승인관문-훅/README.md 보고 훅 켜 줘"라고 시켜도 된다)
3. 새 세션을 열어 시험한다 (데스크톱 앱과 터미널이 같은 설정 파일을 쓴다. 터미널에서는 `/hooks`로 등록 확인)

## 무엇을 막나
- 이름에 post · publish · send · upload · schedule 등이 들어간 MCP 도구 (SNS 게시 · 메일 발송 같은 외부 동작)
- 외부 서버로 데이터를 보내는 `curl` 명령, 파일 삭제 명령
- 막는 방식은 "거절"이 아니라 "사용자에게 묻기"다. 허락하면 진행된다

## 시험
"output 폴더에 있는 파일 하나 지워 줘"라고 시켜 보면, 삭제 직전에 확인 창이 뜬다.
