리부팅랩 × jinbro 오프라인 올데이 (2026-11-01)
수업 순서대로 번호를 붙였습니다. 회색 상자 안 문장을 복사해서 **Claude 데스크톱 앱 Code 탭의 입력창**에 붙여넣으세요.
`<내 제품>`, `<주소>`처럼 꺾쇠로 된 곳은 내 것으로 바꿉니다.
막히면 언제든 수업 코치에게: `/jinbro-class` (3번에서 설치). 번호를 붙이면 그 실습부터 안내합니다. 예: `/jinbro-class 6`

## 오전 · 클로드코드 입문

오전 실습은 바탕화면에 만든 **`my-agent` 폴더**에서 합니다. 실습 자료(예시 제품 '아침결 그래놀라' 소개서 · 후기 · 인터뷰)는 3번에서 수업 코치를 설치하고 처음 부를 때 이 폴더에 깔립니다. 내 제품 자료가 없으면 예시 자료로 그대로 따라 하면 됩니다.

### 1. 설치
1. https://claude.ai/download 에서 맥 · 윈도우 설치 파일을 받아 실행 (이미 Claude 앱이 있으면 최신 버전으로 업데이트)
2. 앱을 열고 Pro 이상 구독한 Claude 계정으로 로그인
3. 왼쪽 위 **Code** 탭 클릭. "무엇을 맡길까요?" 같은 입력창이 보이면 성공

- Code 탭에서 업그레이드 안내가 뜨면: 무료 플랜. Pro 이상으로 업그레이드
- 온라인 로그인 안내가 뜨면: 브라우저에서 로그인을 마치고 앱을 껐다 켜기
- 윈도우에서 Git 설치를 요구하면: 앱을 업데이트. 그래도 나오면 Git(git-scm.com) 설치
- 403 · 인증 오류: 로그아웃 뒤 다시 로그인

### 2. 첫 실행
바탕화면에 빈 폴더 `my-agent`를 만듭니다. 맥은 바탕화면에서 오른쪽 클릭 → 새로운 폴더, 윈도우는 바탕화면에서 오른쪽 클릭 → 새로 만들기 → 폴더. (아래 Open folder… 창에서 바로 새 폴더를 만들어도 됩니다)
1. 입력창 아래 버튼 줄의 맨 앞, 환경을 **Local**로
2. 그 옆 폴더 버튼 → **Open folder…** → 바탕화면의 `my-agent`
3. 입력창 아래 권한 모드 버튼이 **Manual**인지 확인 (앱은 폴더마다 마지막에 고른 모드를 기억합니다), 모델은 기본값
```
안녕, 이 폴더에 뭐가 있는지 알려 줘
```
아직 비어 있다고 답하면 정상입니다. 실습 자료는 3번에서 깔립니다.

### 3. 수업 코치 설치
오늘 실습을 옆자리에서 안내하는 스킬입니다. git 없이 한 줄로 설치됩니다. my-agent 세션 입력창에:
```
https://github.com/Jinbro98/jinbro-class 의 README를 보고 수업 코치 스킬을 설치해 줘
```
설치 명령을 실행해도 되냐고 물으면 읽고 허용합니다. 끝나면 **새 세션**(+ New)을 열고 my-agent 폴더를 고른 뒤:
```
/jinbro-class
```
코치를 처음 부르면 이 폴더에 실습 자료(`자료/` · `프롬프트팩.md` · `실습안내.md` 등)를 깝니다. 허락 질문이 뜨면 읽고 허용하세요.
- 터미널에 직접 붙여 넣어도 됩니다 (git 필요 없음). 맥은 터미널 앱에:
```
curl -fsSL https://raw.githubusercontent.com/Jinbro98/jinbro-class/main/install.sh | bash
```
  윈도우는 PowerShell에:
```
irm https://raw.githubusercontent.com/Jinbro98/jinbro-class/main/install.ps1 | iex
```
- 와이파이 · 깃허브가 막히면 강사가 나눠 주는 예비 압축(`my-agent`)을 바탕화면에 풀고, 그 폴더를 연 세션에서:
```
이 폴더의 수업코치/jinbro-class 폴더를 내 개인 스킬 폴더(~/.claude/skills/jinbro-class)로 복사해 줘
```
- 이후 언제든 `/jinbro-class 6`처럼 번호를 붙이면 그 실습부터 안내합니다. 번호는 화면 왼쪽 위 '실습 N' 배지 = 이 팩의 번호
- `/jinbro-class 컨텍스트가 뭐예요?`처럼 수업 개념을 물어봐도 됩니다

### 4. 첫 업무: 답 대신 파일
```
자료 폴더의 아침결_소개서.md를 읽고, 한 장 요약 파일 만들어 줘. 파일 이름은 제품요약.md
```
내 자료로 할 때는 `아침결_소개서.md` 자리에 내 파일 이름을 넣습니다. 자료가 웹사이트라면:
```
<주소> 를 읽고, 내 제품 한 장 요약 파일 만들어 줘. 파일 이름은 제품요약.md
```
- 허락 질문이 뜨면 바뀔 내용을 보고 허용을 누릅니다. 소개서 파일을 입력창에 끌어다 놓아 첨부해도 됩니다
- 끝나면 파인더 · 탐색기에서 `제품요약.md`를 열어 봅니다. `my-agent` 맨 위나 `자료` 폴더 안에 생깁니다. 어디에 있든 클로드가 찾아 읽으니 괜찮습니다 (맨 위에 두고 싶으면 `이 폴더 맨 위에 저장해 줘`)
- 화면에 지나간 `Read` → `Write` 줄에서 에이전트가 읽고, 쓰고, 확인하는 순서를 찾아봅니다

### 5. 계획부터 받기 (Plan 모드)
입력창 아래 **권한 모드 버튼**(Manual)을 눌러 **Plan**으로 바꾼 뒤 (단축키 맥 Cmd + Shift + M, 윈도우 Ctrl + Shift + M):
```
자료 폴더와 제품요약.md로 상세페이지 문구 초안 만들어 줘. 파일 이름은 상세페이지_초안.md
```
계획이 나오면 바로 승인하지 말고 한 번 고쳐 봅니다. 내 자료로 할 때는 내 후기나 고객의 말로 바꿉니다.
```
고객후기.md 문장 두 개를 그대로 넣어 줘
```
- 고친 계획이 괜찮으면 승인합니다. 승인 선택지가 여러 개면 **하나씩 직접 승인하는 쪽**을 고릅니다. auto · 자동 수락이 붙은 쪽을 누르면 그 모드로 넘어갑니다
- 승인 뒤 권한 모드 버튼이 **Manual**인지 확인합니다

### 6. 컨텍스트 눈으로 보기
```
/context
```
지금 작업 기억이 얼마나 찼는지 봅니다 (세션 정보의 Context 카드로 봐도 됩니다). 그다음 긴 자료를 읽힙니다.
```
자료/고객인터뷰.md 읽고, 고객이 실제로 쓴 말 5개를 고객의말.md로 저장해 줘
```
다시 `/context`를 입력해 읽은 파일만큼 늘어난 칸을 봅니다.
이제 **새 세션**(사이드바 + New, 맥 Cmd + N · 윈도우 Ctrl + N)을 열고 my-agent 폴더를 고른 뒤:
```
아까 뽑은 고객의 말 알려 줘
```
새 세션은 이전 대화를 모릅니다. 대신 폴더의 `고객의말.md`를 읽고 답합니다. 남길 건 파일로.
- 대화가 길어지면 `/compact`로 요약하고 같은 일을 이어 갑니다

### 7. CLAUDE.md 규칙 한 장
먼저 규칙 없이 한 번 받아 둡니다 (8번에서 비교합니다).
```
제품 소개 한 문단 써 줘
```
그다음 아래 규칙을 내 말투에 맞게 바꿔서 넣으세요.
```
이 폴더에 CLAUDE.md를 만들고 아래 규칙을 적어 줘.
## 말투
- 답은 한국어로, 결론부터 3줄
## 파일 이름
- 날짜_내용.md (예: 20261101_제품요약.md)
## 하지 말 것
- 파일을 지우기 전에 반드시 묻기
- "혁신적인", "차별화된" 같은 과장 표현 금지
```

### 8. 규칙 전후 비교
규칙을 넣은 뒤 **새 세션**(+ New)을 열고 my-agent 폴더를 골라 같은 요청을 다시 합니다.
```
제품 소개 한 문단 써 줘
```
7번에서 받아 둔 답과 무엇이 달라졌는지 한 가지만 찾아봅니다.

### 9. 내 첫 스킬
```
제품 한 줄 카피 10개를 뽑는 스킬 만들어 줘. 이름은 oneline-copy.
절차: 제품요약.md를 먼저 읽기 → 고객이 실제로 쓰는 말로 10개 → 가장 좋은 3개 추천과 이유
```
만들어지면 입력창에 `/`를 입력해 목록에서 `oneline-copy`를 고르고 Enter.
```
/oneline-copy
```
- 목록에 안 보이면 새 세션(+ New)을 열고 다시 `/`
- 결과가 마음에 안 들면 결과 말고 SKILL.md를 고치기: `oneline-copy 스킬에 '과장 표현 쓰지 않기' 단계를 추가해 줘`

### 10. 커넥터 연결해 보기
입력창 옆 **+** → **커넥터 추가** (또는 사이드바 **Customize**) → 평소 쓰는 서비스 하나(구글 캘린더 · 구글 드라이브 · 노션 등) → 로그인.
권한 화면에서 무엇을 읽고 쓸 수 있는지 읽습니다. 연결한 서비스에 맞는 문장 하나를 넣습니다.
```
구글 캘린더에서 이번 주 일정 읽고, 마케팅 관련 일정만 표로 정리해 줘
```
```
구글 드라이브에서 '소개서'가 들어간 파일을 찾아서 목록으로 보여 줘
```
```
노션에서 마케팅 관련 페이지를 찾아서 제목과 한 줄 요약을 표로 정리해 줘
```
- 커넥터 도구를 쓸 때도 허락 질문이 뜹니다. 읽고 허용
- 계정 연결이 부담되면 목록만 보고, 내 일에 쓸 만한 커넥터 하나를 메모해 둡니다
- 회사 계정은 관리자가 막아 두었을 수 있습니다. 연결을 끊으려면 사이드바 Customize에서 끄기

### 11. 플러그인 둘러보기
입력창 옆 **+** → **플러그인 추가** → 플러그인 브라우저. 관심 가는 플러그인 하나를 골라 카드에서 네 칸을 읽습니다.

| 볼 것 | 질문 |
|---|---|
| 무엇을 | 어떤 일을 대신해 주나 |
| 누가 | 만든 곳 · 공식 여부 |
| 안에 든 것 | 스킬 · 서브에이전트 · 훅 · 커넥터 중 무엇 |
| 범위 | 나만 · 이 폴더만 |

- 설치는 선택. 설치했다면 입력창에 `/`를 쳐서 새로 생긴 명령을 찾아봅니다
- 안 쓰면 사이드바 Customize에서 끄기
- 마케팅 스킬 묶음은 오후에 스타터 키트로 쓰니 지금은 받지 않아도 됩니다

### 12. 서브에이전트로 나눠 조사
`<내 업종>` 자리에 내 업종을 넣습니다 (예시 제품이면 '그래놀라').
```
<내 업종> 브랜드 세 곳을 서브에이전트 세 개로 나눠 동시에 조사하고, 결과를 경쟁조사.md 비교표 하나로 합쳐 줘.
비교 칸: 가격 · 강점 · 말투 · 우리와 다른 점. 출처 주소도 적어 줘
```
경쟁 브랜드를 이미 알면 `<브랜드1> · <브랜드2> · <브랜드3>을 서브에이전트 세 개로 나눠 …`로 바꿉니다.
- 진행 화면에서 서브에이전트가 각자 따로 검색하고, 메인 대화에는 결과만 돌아오는 것을 봅니다
- 웹 자료의 숫자 · 가격은 틀릴 수 있습니다. 출처 주소로 확인합니다

### 13. 오전 종합 실습
**새 세션**(+ New) → my-agent 폴더 → 권한 모드 **Plan**으로 바꾼 뒤:
```
제품요약.md · 고객의말.md · 경쟁조사.md를 읽고 이번 주 인스타 게시물 3개 초안을 만들어 줘.
카피는 /oneline-copy로 먼저 뽑고, 게시물마다 경쟁사와 다른 점을 하나씩 넣어 줘.
게시물 1개당 파일 1개로 저장
```
계획을 보고 고칠 게 있으면 고치고, 하나씩 직접 승인합니다. 끝나면 파일을 열어 확인합니다.
- [ ] 게시물 파일 3개가 생겼다
- [ ] 고객이 쓴 말과 경쟁사와 다른 점이 들어갔다
- [ ] CLAUDE.md 규칙(말투 · 파일 이름 · 금지 표현)을 지켰다

앞 실습 파일이 없으면 있는 파일만 읽게 바꿉니다: `제품요약.md만 읽고 …`

### 오전에 나온 버튼 · 명령 모음
| 어디 · 무엇 | 하는 일 |
|---|---|
| 입력창 아래 권한 모드 버튼 (Cmd/Ctrl + Shift + M) | Manual · Accept edits · Plan · Auto 고르기 |
| 입력창 아래 모델 버튼 (Cmd/Ctrl + Shift + I) | 모델 바꾸기 |
| 사이드바 + New (Cmd/Ctrl + N) | 새 세션 (새 주제는 새 세션) |
| 사이드바의 지난 세션 | 클릭하면 이어서 열기 |
| 입력창 옆 + | 파일 첨부 · 슬래시 명령 · 커넥터(MCP) 추가 · 플러그인 추가 |
| 사이드바 Customize | 커넥터 · 스킬 · 플러그인 관리 |
| `/` | 스킬 · 명령 목록 |
| `/context` | 작업 기억이 얼마나 찼는지 (세션 정보의 Context 카드에도) |
| `/compact` | 지금까지를 요약하고 이어 가기 |
| `/btw` (Cmd/Ctrl + ;) | 흐름을 끊지 않는 곁가지 질문 |
| Esc | 클로드 멈추기 |

## 오후 · 마케팅 에이전트 만들기

### 14. 스타터 키트 풀고 오전 폴더 합치기
`marketing-agent` 압축을 바탕화면에 풀고, **새 세션**(+ New) → 폴더 버튼 → **Open folder…** → `marketing-agent`를 고릅니다. 권한 모드 버튼이 **Manual**인지 확인한 뒤:
```
바탕화면의 my-agent 폴더에서 자료 폴더와 .claude/skills/oneline-copy 스킬을 이 폴더로 복사하고,
my-agent의 고객의말.md · 경쟁조사.md는 이 폴더 자료 폴더 안으로 복사해 줘.
my-agent의 CLAUDE.md 규칙(파일 이름 규칙은 빼고)을 이 폴더 CLAUDE.md 맨 아래 '내 규칙' 칸에 옮겨 줘.
oneline-copy 스킬은 제품요약.md 대신 지금 제품의 PROFILE.md를 읽게 고쳐 줘
```
다른 폴더를 읽어도 되냐고 물으면 허용. 끝나면 `.claude/skills/`에 스킬이 8개 있는지 확인합니다.
(`.claude` 폴더가 안 보이면 맥은 Cmd + Shift + . / 윈도우 탐색기는 보기 → 숨긴 항목)

### 15. 입사 첫날 인터뷰 → PROFILE.md
```
CLAUDE.md 읽고, 내 제품으로 입사 첫날 인터뷰 시작해 줘. 자료는 자료/<파일 이름>
```
웹사이트로 할 때:
```
CLAUDE.md 읽고, 내 제품으로 입사 첫날 인터뷰 시작해 줘. 웹사이트는 <주소>
```
- 손님이 실제로 하는 말을 그대로 답하면 카피가 좋아집니다
- 질문이 길어지면: `나머지는 TBD로 두고 PROFILE.md 초안 먼저 보여 줘`
- 틀린 곳은 말로 고치기: `고객 칸을 '아침을 자주 거르는 30대 직장인'으로 바꿔 줘`

### 16. 프로필 없이 vs 프로필 연결 후
**새 세션**(+ New)을 열고 폴더 버튼에서 **아무것도 없는 새 폴더**(예: 바탕화면에 `빈폴더`를 만들어 고르기)를 골라 한 번, `marketing-agent` 세션에서 한 번 똑같이:
```
<내 제품> 신제품 출시 인스타 카피 3개 써 줘
```
두 결과를 나란히 놓고 무엇이 달라졌는지 봅니다.

### 16-2. copywriting 스킬로 상세페이지 첫 화면
`marketing-agent` 세션에서 스킬 이름을 불러 시킵니다:
```
/copywriting <내 제품> 상세페이지 첫 화면 문구 써 줘. 손님은 <어디>에서 들어오고, 원하는 행동은 <구매 · 예약 · 문의>야
```
아침결 예: `/copywriting 아침결 스마트스토어 상세페이지 첫 화면 문구 써 줘. 손님은 인스타에서 들어오고, 원하는 행동은 정기배송 신청이야`

답과 `output/<날짜-주제>/` 파일에서 세 가지를 찾습니다: 제목 · 부제 · 버튼 문구, 제목 다른 안과 고른 이유, `[NEED]` 표시(근거가 없어 비워 둔 곳 = 내가 줄 정보).
- 다른 안으로 바꿀 때: `헤드라인을 B안으로 바꿔 줘`
- `[NEED]`를 채울 때: 비워 둔 정보를 알려 주기. 예: `해지 조건은 <조건>이야. 버튼 아래 한 줄로 넣어 줘`
- 질문을 여러 개 하면: `모르는 건 [NEED]로 두고 먼저 써 줘`

### 17. 전략부터
