## 오전 · 클로드코드 입문

오전 실습은 바탕화면에 만든 **`my-agent` 폴더**에서 합니다. 실습 자료(예시 제품 '아침결 그래놀라' 소개서 · 후기 · 인터뷰)는 3번에서 수업 코치를 설치하고 처음 부를 때 이 폴더에 깔립니다. 내 제품 자료가 없으면 예시 자료로 그대로 따라 하면 됩니다.

### 1. 설치
1. https://claude.ai/download 에서 맥 · 윈도우 설치 파일을 받아 실행 (이미 Claude 앱이 있으면 최신 버전으로 업데이트)
2. 앱을 열고 Pro 이상 구독한 Claude 계정으로 로그인
3. 왼쪽 위 **Code** 탭 클릭. "무엇을 맡길까요?" 같은 입력창이 보이면 성공

- Code 탭에서 업그레이드 안내가 뜨면: 무료 플랜. Pro 이상으로 업그레이드
- 온라인 로그인 안내가 뜨면: 브라우저에서 로그인을 마치고 앱을 껐다 켜기
- 윈도우에서 Git 설치를 요구하면: 앱을 업데이트. 그래도 나오면 Git(git-scm.com) 설치
- 403 · 인증 오류: 로그아웃 뒤 다시 로그인

### 2. 첫 실행
바탕화면에 빈 폴더 `my-agent`를 만듭니다. 맥은 바탕화면에서 오른쪽 클릭 → 새로운 폴더, 윈도우는 바탕화면에서 오른쪽 클릭 → 새로 만들기 → 폴더. (아래 Open folder… 창에서 바로 새 폴더를 만들어도 됩니다)
1. 입력창 아래 버튼 줄의 맨 앞, 환경을 **Local**로
2. 그 옆 폴더 버튼 → **Open folder…** → 바탕화면의 `my-agent`
3. 입력창 아래 권한 모드 버튼이 **Manual**인지 확인 (앱은 폴더마다 마지막에 고른 모드를 기억합니다), 모델은 기본값
```
안녕, 이 폴더에 뭐가 있는지 알려 줘
```
아직 비어 있다고 답하면 정상입니다. 실습 자료는 3번에서 깔립니다.

### 3. 수업 코치 설치
오늘 실습을 옆자리에서 안내하는 스킬입니다. git 없이 한 줄로 설치됩니다. my-agent 세션 입력창에:
```
https://github.com/Jinbro98/jinbro-class 의 README를 보고 수업 코치 스킬을 설치해 줘
```
설치 명령을 실행해도 되냐고 물으면 읽고 허용합니다. 끝나면 **새 세션**(+ New)을 열고 my-agent 폴더를 고른 뒤:
```
/jinbro-class
```
코치를 처음 부르면 이 폴더에 실습 자료(`자료/` · `프롬프트팩.md` · `실습안내.md` 등)를 깝니다. 허락 질문이 뜨면 읽고 허용하세요.
- 터미널에 직접 붙여 넣어도 됩니다 (git 필요 없음). 맥은 터미널 앱에:
```
curl -fsSL https://raw.githubusercontent.com/Jinbro98/jinbro-class/main/install.sh | bash
```
  윈도우는 PowerShell에:
```
irm https://raw.githubusercontent.com/Jinbro98/jinbro-class/main/install.ps1 | iex
```
- 와이파이 · 깃허브가 막히면 강사가 나눠 주는 예비 압축(`my-agent`)을 바탕화면에 풀고, 그 폴더를 연 세션에서:
```
이 폴더의 수업코치/jinbro-class 폴더를 내 개인 스킬 폴더(~/.claude/skills/jinbro-class)로 복사해 줘
```
- 이후 언제든 `/jinbro-class 6`처럼 번호를 붙이면 그 실습부터 안내합니다. 번호는 화면 왼쪽 위 '실습 N' 배지 = 이 팩의 번호
- `/jinbro-class 컨텍스트가 뭐예요?`처럼 수업 개념을 물어봐도 됩니다

### 4. 첫 업무: 답 대신 파일
```
자료 폴더의 아침결_소개서.md를 읽고, 한 장 요약 파일 만들어 줘. 파일 이름은 제품요약.md
```
내 자료로 할 때는 `아침결_소개서.md` 자리에 내 파일 이름을 넣습니다. 자료가 웹사이트라면:
```
<주소> 를 읽고, 내 제품 한 장 요약 파일 만들어 줘. 파일 이름은 제품요약.md
```
- 허락 질문이 뜨면 바뀔 내용을 보고 허용을 누릅니다. 소개서 파일을 입력창에 끌어다 놓아 첨부해도 됩니다
- 끝나면 파인더 · 탐색기에서 `제품요약.md`를 열어 봅니다. `my-agent` 맨 위나 `자료` 폴더 안에 생깁니다. 어디에 있든 클로드가 찾아 읽으니 괜찮습니다 (맨 위에 두고 싶으면 `이 폴더 맨 위에 저장해 줘`)
- 화면에 지나간 `Read` → `Write` 줄에서 에이전트가 읽고, 쓰고, 확인하는 순서를 찾아봅니다

### 5. 계획부터 받기 (Plan 모드)
입력창 아래 **권한 모드 버튼**(Manual)을 눌러 **Plan**으로 바꾼 뒤 (단축키 맥 Cmd + Shift + M, 윈도우 Ctrl + Shift + M):
```
자료 폴더와 제품요약.md로 상세페이지 문구 초안 만들어 줘. 파일 이름은 상세페이지_초안.md
```
계획이 나오면 바로 승인하지 말고 한 번 고쳐 봅니다. 내 자료로 할 때는 내 후기나 고객의 말로 바꿉니다.
```
고객후기.md 문장 두 개를 그대로 넣어 줘
```
- 고친 계획이 괜찮으면 승인합니다. 승인 선택지가 여러 개면 **하나씩 직접 승인하는 쪽**을 고릅니다. auto · 자동 수락이 붙은 쪽을 누르면 그 모드로 넘어갑니다
- 승인 뒤 권한 모드 버튼이 **Manual**인지 확인합니다

### 6. 컨텍스트 눈으로 보기
```
/context
```
지금 작업 기억이 얼마나 찼는지 봅니다 (세션 정보의 Context 카드로 봐도 됩니다). 그다음 긴 자료를 읽힙니다.
```
자료/고객인터뷰.md 읽고, 고객이 실제로 쓴 말 5개를 고객의말.md로 저장해 줘
```
다시 `/context`를 입력해 읽은 파일만큼 늘어난 칸을 봅니다.
이제 **새 세션**(사이드바 + New, 맥 Cmd + N · 윈도우 Ctrl + N)을 열고 my-agent 폴더를 고른 뒤:
```
아까 뽑은 고객의 말 알려 줘
```
새 세션은 이전 대화를 모릅니다. 대신 폴더의 `고객의말.md`를 읽고 답합니다. 남길 건 파일로.
- 대화가 길어지면 `/compact`로 요약하고 같은 일을 이어 갑니다

### 7. 마케팅 작업실 규칙 (CLAUDE.md)
먼저 **새 세션**(+ New)을 열고 my-agent 폴더에서 규칙 없이 한 번 받아 둡니다 (8번에서 비교합니다).
```
인스타에 올릴 제품 소개 글 써 줘
```
그다음 아래 문장을 **통째로** 붙여 넣습니다. 클로드가 자료를 읽고 `[ ]` 칸을 채워 CLAUDE.md를 씁니다. 말투 · 금지 표현은 내 브랜드에 맞게 고쳐서 보내도 됩니다.
```
이 폴더를 내 제품 마케팅 작업실로 쓸 거야. 자료 폴더의 파일과 제품요약.md · 고객의말.md를 읽고(없는 파일은 건너뛰기), 이 폴더 맨 위에 CLAUDE.md를 만들어 줘.
아래 틀을 그대로 쓰고 [ ] 칸은 자료에서 찾아 채워. 자료에 없는 건 지어내지 말고 TBD로 둬.

# 마케팅 작업실 규칙

## 1. 너의 역할
너는 이 제품의 마케팅 담당자다. 글을 쓰기 전에 이 파일의 제품 맥락과 규칙부터 따른다.

## 2. 제품 맥락
- 제품: [이름 · 한 줄 소개 · 가격 · 용량 같은 사실]
- 핵심 고객: [누구 · 언제 · 무엇이 불편한지. 두 번째 고객도]
- 고객이 실제로 쓴 말: [따옴표 그대로 3~5개]
- 강점: [사실로 확인되는 것 3개]
- 판매 채널: [채널과 숫자]
- 지금 고민: [자료에 적힌 것]

## 3. 브랜드 말투
- 해요체. 한 문장은 짧게
- 이모지와 느낌표는 쓰지 않는다
- 첫 줄은 고객이 실제로 쓴 말이나 구체적인 장면으로 시작한다
- 금지 표현: [자료에 적힌 쓰지 않는 말], 혁신적인, 차별화된, 프리미엄, 특별한, 건강 효능 약속

## 4. 마케팅 글 쓰는 법
- 쓰기 전에 핵심 고객 중 누구에게 쓰는 글인지 하나 고른다
- 순서: 고객의 말 → 그 고객의 장면 → 사실과 숫자 → 다음 행동 하나
- 어느 브랜드에 붙여도 말이 되는 문장은 지운다

## 5. 결과물 규칙
- 마케팅 글은 대화창에만 두지 말고 파일로 저장한다: 결과물/YYYYMMDD_채널_내용.md
- 파일 맨 위 세 줄: 채널 · 대상 · 핵심 메시지
- 인스타 캡션은 8줄 이내, 해시태그 5개
- 맨 아래에 '확인할 것': 자료로 확인하지 못한 숫자 · 표현

## 6. 하지 말 것
- 자료에 없는 숫자 · 후기 · 수상 경력을 만들지 않는다
- 게시 · 발송은 하지 않는다. 사람이 한다
- 파일을 지우기 전에는 반드시 묻는다

다 만들면 CLAUDE.md 내용을 보여 주고, 고칠 곳이 있는지 물어봐.
```
보여 준 내용에서 틀린 곳은 말로 고칩니다: `금지 표현에 '건강식'도 넣어 줘` / `핵심 고객 1순위를 부모로 바꿔 줘`

### 8. 규칙 전후 비교
**새 세션**(+ New)을 열고 my-agent 폴더에서 7번과 똑같이:
```
인스타에 올릴 제품 소개 글 써 줘
```
사이드바에서 7번의 지난 세션을 열어 두 답을 나란히 봅니다.
- [ ] 제품을 묻지 않고 바로 내 제품 이야기로 썼다
- [ ] 첫 줄이 고객이 실제로 쓴 말이나 장면이다
- [ ] 이모지 · 금지 표현이 없다
- [ ] 저장하라고 안 했는데 `결과물/` 폴더에 파일이 생겼다 (맨 위 세 줄 · 맨 아래 '확인할 것')

### 9. 내 첫 스킬
스킬은 자주 하는 일의 **매뉴얼**입니다. 언제 쓰는지 · 절차 · 결과 형식 · 예시까지 적을수록 매번 같은 품질이 나옵니다.
```
자주 하는 일 하나를 스킬로 만들어 줘. 스킬 이름은 oneline-copy, 파일은 .claude/skills/oneline-copy/SKILL.md.

[언제 쓰나] description에 적기
- 한 줄 카피 · 헤드라인 · 게시물 첫 줄 · 슬로건을 뽑아 달라고 할 때

[절차]
1. CLAUDE.md의 제품 맥락 · 말투 · 금지 표현을 따른다. 제품요약.md · 고객의말.md가 있으면 읽는다
2. 어디에 쓸 카피인지(채널 · 목적) 요청에 없으면 한 번만 묻는다
3. 각도 다섯 가지로 2개씩, 모두 10개 쓴다: 고객이 쓴 말 · 숫자와 사실 · 장면 · 질문 · 비교
4. 한 줄은 25자 안팎. 금지 표현이 들어가거나 경쟁사도 그대로 쓸 수 있는 문장은 버리고 다시 쓴다
5. 가장 좋은 3개를 고르고, 고른 이유를 한 줄씩

[결과 형식]
- 결과물/YYYYMMDD_한줄카피.md에 저장: 각도별 표(각도 · 카피 · 근거 자료) → 추천 3개와 이유
- 대화창에는 추천 3개만 짧게

[원칙]
- 제품 이름 · 가격 · 고객의 말 같은 제품 사실은 스킬에 적지 않는다. 제품이 바뀌어도 쓸 수 있게 매번 CLAUDE.md에서 읽는다

[좋은 예 · 나쁜 예]
- 좋은 예: 고객이 쓴 말이나 숫자가 들어가 그 제품에만 맞는 문장
- 나쁜 예: "새로운 기준", "특별한 경험"처럼 어느 회사에 붙여도 되는 문장

다 만들면 SKILL.md를 보여 줘.
```
`.claude` 폴더에 써도 되냐고 물으면 허용. 만들어지면 **새 세션**(+ New)에서 `/`를 입력해 목록의 `oneline-copy`를 고르고 채널을 붙여 보냅니다.
```
/oneline-copy 인스타 게시물 첫 줄
```
`결과물/` 폴더의 한줄카피 파일에서 각도별 10개 · 근거 · 추천 3개를 봅니다.
- 목록에 안 보이면 새 세션(+ New)을 열고 다시 `/`
- 결과가 마음에 안 들면 결과 말고 SKILL.md를 고치기: `oneline-copy 스킬에 '추천 3개는 각도가 겹치지 않게' 규칙을 추가해 줘`

### 10. 커넥터 연결해 보기
입력창 옆 **+** → **커넥터 추가** (또는 사이드바 **Customize**) → 평소 쓰는 서비스 하나(구글 캘린더 · 구글 드라이브 · 노션 등) → 로그인.
권한 화면에서 무엇을 읽고 쓸 수 있는지 읽습니다. 연결한 서비스에 맞는 문장 하나를 넣습니다.
```
구글 캘린더에서 이번 주 일정 읽고, 마케팅 관련 일정만 표로 정리해 줘
```
```
구글 드라이브에서 '소개서'가 들어간 파일을 찾아서 목록으로 보여 줘
```
```
노션에서 마케팅 관련 페이지를 찾아서 제목과 한 줄 요약을 표로 정리해 줘
```
- 커넥터 도구를 쓸 때도 허락 질문이 뜹니다. 읽고 허용
- 계정 연결이 부담되면 목록만 보고, 내 일에 쓸 만한 커넥터 하나를 메모해 둡니다
- 회사 계정은 관리자가 막아 두었을 수 있습니다. 연결을 끊으려면 사이드바 Customize에서 끄기

### 11. 플러그인 둘러보기
입력창 옆 **+** → **플러그인 추가** → 플러그인 브라우저. 관심 가는 플러그인 하나를 골라 카드에서 네 칸을 읽습니다.

| 볼 것 | 질문 |
|---|---|
| 무엇을 | 어떤 일을 대신해 주나 |
| 누가 | 만든 곳 · 공식 여부 |
| 안에 든 것 | 스킬 · 서브에이전트 · 훅 · 커넥터 중 무엇 |
| 범위 | 나만 · 이 폴더만 |

- 설치는 선택. 설치했다면 입력창에 `/`를 쳐서 새로 생긴 명령을 찾아봅니다
- 안 쓰면 사이드바 Customize에서 끄기
- 마케팅 스킬 묶음은 오후에 스타터 키트로 쓰니 지금은 받지 않아도 됩니다

### 12. 서브에이전트로 나눠 조사
`<내 업종>` 자리에 내 업종을 넣습니다 (예시 제품이면 '그래놀라').
```
<내 업종> 브랜드 세 곳을 서브에이전트 세 개로 나눠 동시에 조사하고, 결과를 경쟁조사.md 비교표 하나로 합쳐 줘.
비교 칸: 가격 · 강점 · 말투 · 우리와 다른 점. 출처 주소도 적어 줘
```
경쟁 브랜드를 이미 알면 `<브랜드1> · <브랜드2> · <브랜드3>을 서브에이전트 세 개로 나눠 …`로 바꿉니다.
- 진행 화면에서 서브에이전트가 각자 따로 검색하고, 메인 대화에는 결과만 돌아오는 것을 봅니다
- 웹 자료의 숫자 · 가격은 틀릴 수 있습니다. 출처 주소로 확인합니다

### 13. 오전 종합 실습
**새 세션**(+ New) → my-agent 폴더 → 권한 모드 **Plan**으로 바꾼 뒤:
```
제품요약.md · 고객의말.md · 경쟁조사.md를 읽고 이번 주 인스타 게시물 3개 초안을 만들어 줘.
카피는 /oneline-copy로 먼저 뽑고, 게시물마다 경쟁사와 다른 점을 하나씩 넣어 줘.
게시물 1개당 파일 1개로 저장
```
계획을 보고 고칠 게 있으면 고치고, 하나씩 직접 승인합니다. 끝나면 파일을 열어 확인합니다.
- [ ] 게시물 파일 3개가 생겼다
- [ ] 고객이 쓴 말과 경쟁사와 다른 점이 들어갔다
- [ ] CLAUDE.md 규칙(첫 줄은 고객의 말 · 이모지 없음 · `결과물/` 파일 · 확인할 것)을 지켰다

앞 실습 파일이 없으면 있는 파일만 읽게 바꿉니다: `제품요약.md만 읽고 …`


### 16-2. copywriting 스킬로 상세페이지 첫 화면
먼저 사용법을 물어봐도 됩니다: `/copywriting 이 스킬 어떻게 써? 읽어 보고 내가 줄 재료를 알려 줘`
`marketing-agent` 세션에서 스킬 이름을 불러 시킵니다:
```
/copywriting <내 제품> 상세페이지 첫 화면 문구 써 줘. 손님은 <어디>에서 들어오고, 원하는 행동은 <구매 · 예약 · 문의>야
```
아침결 예: `/copywriting 아침결 스마트스토어 상세페이지 첫 화면 문구 써 줘. 손님은 인스타에서 들어오고, 원하는 행동은 정기배송 신청이야`

답과 `output/<날짜-주제>/` 파일에서 세 가지를 찾습니다: 제목 · 부제 · 버튼 문구, 제목 다른 안과 고른 이유, `[NEED]` 표시(근거가 없어 비워 둔 곳 = 내가 줄 정보).
- 다른 안으로 바꿀 때: `헤드라인을 B안으로 바꿔 줘`
- `[NEED]`를 채울 때: 비워 둔 정보를 알려 주기. 예: `해지 조건은 <조건>이야. 버튼 아래 한 줄로 넣어 줘`
- 질문을 여러 개 하면: `모르는 건 [NEED]로 두고 먼저 써 줘`
- 지금 쓰는 문구가 있으면 진단부터: `/copywriting 지금 상세페이지 첫 문구는 '<지금 문구>'야. 진단부터 하고 고객 단어로 V2를 써 줘`

### 19-2. 캠페인 팀원(서브에이전트) 만들고 맡기기
입력창 아래 권한 모드를 **Plan**으로 바꾸고 보냅니다. 계획을 읽고 승인, `.claude` 폴더에 써도 되냐고 물으면 허용.
```
출시 · 행사 캠페인을 맡길 팀원(서브에이전트)을 하나 만들어 줘.
- 이름: campaign-planner, 파일: .claude/agents/campaign-planner.md
- 하는 일: 주제 하나(신제품 출시 · 시즌 행사 등)를 받으면 그 제품의 캠페인 기획서 한 장을 만든다
- 먼저 읽을 것: docs/products.md → products/<제품>/PROFILE.md · decisions.md · strategy/ 문서
- 꼭 쓸 스킬: launch(출시 단계 · 채널) · content-strategy(무엇을 왜) · copywriting(헤드라인 · 버튼 문구) · social(게시물). 쓰기 전에 .claude/skills/<스킬>/SKILL.md를 읽고 그 절차를 따른다
- 결과: products/<제품>/strategy/캠페인-<주제>.md 한 파일
  1 목표(숫자 · 기간) 2 핵심 메시지와 헤드라인 3안 3 채널별 계획(내 채널 · SNS · 협업) 4 출시 전 · 당일 · 뒤 일정표 5 게시물 초안 3개(첫 줄 · 본문 · 버튼 문구) 6 확인할 것
- description에 적기: 부르는 쪽은 제품과 주제만 넘기고, 결과 형식은 이 파일의 여섯 칸을 그대로 따른다
- 지킬 것: decisions.md와 부딪히면 멈추고 묻는다 · 자료에 없는 숫자는 [NEED]로 비운다 · 게시 · 발송 · 광고 집행은 하지 않는다
```
만들어지면 **새 세션**(+ New)을 엽니다 (팀원 파일은 새 세션에서 인식됩니다). 모드는 **Manual**로 두고:
```
campaign-planner에게 맡겨 줘: <내 제품> <주제> 캠페인. 팀원 파일의 여섯 칸 그대로, 게시물 초안 3개까지
```
아침결 예: `campaign-planner에게 맡겨 줘: 아침결 12월 한 끼 소포장 출시 캠페인. 팀원 파일의 여섯 칸 그대로, 게시물 초안 3개까지`

`products/<내 제품>/strategy/캠페인-<주제>.md`를 열어 여섯 칸(목표 · 헤드라인 3안 · 채널별 계획 · 일정표 · 게시물 초안 3개 · 확인할 것)을 봅니다.
- `[NEED]` 채우기: `출시일은 <날짜>야. 캠페인 파일 일정표에 날짜를 넣어 줘`
- 보고한 결정 기록 후보가 맞으면: `기록 후보 중 1번만 decisions.md에 기록해 줘`

부록 A로 53개를 한 번에 받아도 되고, 필요한 것만 말로 받아도 됩니다.
```
github.com/coreyhaines31/marketingskills 에서 marketing-psychology 스킬을 이 폴더 .claude/skills/에 받아 줘
```
| 스킬 | 하는 일 | 언제 |
|---|---|---|
| `marketing-psychology` | 사람이 사는 이유 · 심리 원리를 마케팅에 적용 | 카피 · 혜택에 설득력을 더할 때 |
| `offers` | 파는 것의 구성 · 가치 표현 · 보너스 · 보장 설계 | 할인 말고 줄 수 있는 걸 찾을 때 |
| `customer-research` | 고객 인터뷰 · 후기 · 설문 분석 | 고객의 말을 더 모으고 싶을 때 |
| `copy-editing` | 이미 쓴 글 검토 · 다듬기 | 내 초안을 고칠 때 |
| `lead-magnets` | 연락처를 받는 무료 자료 기획 (체크리스트 · 템플릿 등) | 알림 신청 · 체험단을 모을 때 |
| `marketing-ideas` | 마케팅 아이디어 목록 (소프트웨어 기준이라 내 업종에 맞게 골라 쓰기) | 뭘 해야 할지 막힐 때 |
| `events` | 행사 기획 · 운영 (웨비나 · 워크숍 · 밋업 등) | 오프라인 행사 · 시즌 이벤트 |

스킬은 미국 기준으로 쓰여 있습니다. 스마트스토어 · 카카오 · 네이버 같은 내 맥락은 PROFILE.md와 CLAUDE.md가 채웁니다.

### C. 커넥터(MCP) 연결 예시 (노션)
입력창 옆 **+ → 커넥터 추가** → 목록에서 노션 → 로그인. 관리 · 해제는 사이드바 **Customize → Connectors**.
연결 뒤:
```
노션의 <페이지 이름> 기획서 읽고 이번 주 콘텐츠 아이디어 5개 뽑아 줘
```
회사 자료는 어느 서버를 거치는지 확인하고 연결합니다.

### D. 승인 관문 훅 켜기 (선택 · 파이썬 3 필요)
```
extras/승인관문-훅/README.md 를 읽고 그대로 훅을 켜 줘
```
켠 뒤 새 세션을 열고 시험: `output 폴더의 파일 하나 지워 줘` → 확인 창이 뜨면 정상. 훅은 데스크톱 앱과 터미널이 같은 설정 파일을 씁니다.

### E. 터미널로 쓰고 싶을 때 (선택)
같은 폴더를 터미널에서 열어도 CLAUDE.md · 스킬 · 훅이 그대로 동작합니다.
맥 터미널:
```
curl -fsSL https://claude.ai/install.sh | bash
```
윈도우 PowerShell:
```
irm https://claude.ai/install.ps1 | iex
```
터미널을 새로 열고 `claude --version`으로 확인 → `cd ~/Desktop/marketing-agent` → `claude`. 터미널에서는 `Shift + Tab`으로 권한 모드를 바꿉니다.
