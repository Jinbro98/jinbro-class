# 데스크톱 앱 버튼 지도 · 막힘 해결표

앱 버전 · 언어에 따라 버튼 이름과 위치가 조금 다를 수 있다. 다르면 지어내지 말고 "강사님께 손 들기"로 안내한다.

## 버튼 지도 (Code 탭)
| 어디 · 무엇 | 하는 일 |
|---|---|
| 왼쪽 위 Code 탭 | 클로드코드 화면 (Chat · Cowork 옆) |
| 입력창 아래 환경 버튼 (Local) | 내 컴퓨터에서 일하기 |
| 입력창 아래 폴더 버튼 → Open folder… | 작업 폴더 고르기 |
| 입력창 아래 권한 모드 버튼 (맥 Cmd + Shift + M · 윈도우 Ctrl + Shift + M) | Manual · Accept edits · Plan · Auto |
| 입력창 아래 모델 버튼 (Cmd/Ctrl + Shift + I) | 모델 바꾸기 |
| 사이드바 + New (Cmd/Ctrl + N) | 새 세션 |
| 사이드바의 지난 세션 | 클릭하면 이어서 열기 |
| 입력창 옆 + | 파일 첨부 · 슬래시 명령 · 커넥터 추가 · 플러그인 추가 |
| 사이드바 Customize | 커넥터 · 스킬 · 플러그인 관리 |
| `/` | 스킬 · 명령 목록 |
| `/context` | 작업 기억이 얼마나 찼는지 (세션 정보의 Context 카드에도) |
| `/compact` | 지금까지를 요약하고 이어 가기 |
| `/btw` (Cmd/Ctrl + ;) | 흐름을 끊지 않는 곁가지 질문 |
| Esc | 클로드 멈추기 |
| 허락 질문 카드 | 바뀔 내용을 보고 허용 · 거절 (영어로 Allow · Deny 등으로 보일 수 있음) |

## 막힘 해결표
| 증상 | 원인 | 해결 |
|---|---|---|
| Code 탭에서 업그레이드 안내 | 무료 플랜 | Pro 이상 구독 확인 |
| 온라인 로그인 안내 | 로그인이 덜 끝남 | 브라우저 로그인 마치고 앱 껐다 켜기 |
| 윈도우에서 Git 설치 요구 | 오래된 앱 버전 | 앱 업데이트, 그래도 나오면 git-scm.com에서 Git 설치 |
| 403 · 인증 오류 | 계정 인증 꼬임 | 로그아웃 뒤 다시 로그인 |
| 새로 만든 스킬이 `/` 목록에 없음 | 지금 세션이 시작될 때 없던 스킬 | 새 세션(+ New)에서 다시 `/` |
| `.claude` 폴더가 안 보임 | 이름이 점으로 시작하는 숨김 폴더 | 맥 Cmd + Shift + . / 윈도우 탐색기 보기 → 숨긴 항목 |
| 만든 파일이 어디 있는지 모름 | `자료/` 안에 생겼을 수 있음 | "제품요약.md 어디 있어?"라고 묻기. 위치는 상관없음 |
| 모드 메뉴에 Plan이 없음 | 오래된 앱 버전 | 앱 업데이트 |
| 모드가 Auto로 바뀌어 있음 | 계획 승인 때 auto 쪽을 누름 · 폴더별 기억 | 모드 버튼에서 Manual로 |
| 허락 질문이 너무 많음 | Manual 모드라 정상 | 읽고 허용. 오늘은 Manual 유지 |
| 웹 검색 · 웹 읽기가 계속 막힘 | 허락 거절 · 네트워크 | 허락 질문에서 허용, 와이파이 확인 |
| 커넥터 목록에 회사 서비스가 없음 · 연결 실패 | 관리자 설정 | 개인 계정으로, 아니면 목록만 보기 |
| 사용량 한도 안내 | Pro 사용량 소진 | 잠시 쉬었다 다시, 무거운 일은 나눠서 |
| 윈도우에서 바탕화면 경로를 못 찾음 | 바탕화면이 OneDrive 아래 | "바탕화면의 my-agent 폴더"라고 말로 지정하거나 Open folder…로 직접 열기 |
| 코치 스킬 설치가 실패 | 깃허브 · 와이파이 차단 | 강사의 예비 압축(my-agent)을 풀고 그 안 `수업코치/jinbro-class` 사본으로 설치 |
| 실습 자료 설치가 실패 | 스크립트 실행이 막힘 (윈도우 실행 정책 등) | 코치가 파일을 하나씩 직접 써서 깔기 (SKILL.md '실습 자료 설치') |
