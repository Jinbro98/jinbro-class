# 경쟁조사 (따라잡기용 예시)

> 가상 예시입니다. 실제 브랜드 조사가 아니라 비교표 모양을 보여 주는 파일입니다. 실습 12를 하면 진짜 조사 결과로 바뀝니다.

| | 예시 A · 대형 시리얼 | 예시 B · 수제 그래놀라 공방 | 예시 C · 편의점 아침 대용 |
|---|---|---|---|
| 가격 | 저렴 (마트 할인 잦음) | 비쌈 (소량 생산) | 한 끼 5천~7천 원 |
| 강점 | 어디서나 구함 · 아이 입맛 | 재료 고급 · 선물용 | 바로 사서 먹음 |
| 말투 | 밝고 활기찬 광고체 | 감성적 · 이야기 중심 | 가격 · 할인 중심 |
| 약점 | 단맛이 강함 | 가격 · 구하기 어려움 | 매일 사면 비쌈 · 질림 |
| 우리와 다른 점 | 아침결은 대추로만 단맛 | 아침결은 매일 먹을 가격 · 정기배송 | 아침결은 집에서 3분 · 2주에 한 봉지 |
