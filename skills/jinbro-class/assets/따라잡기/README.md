# 따라잡기 파일

앞 실습을 놓친 수강생이 다음 실습을 바로 해 볼 수 있게 쓰는 예시 결과물입니다. 예시 제품 '아침결 그래놀라'(가상) 기준이라, 내 제품으로 실습 중이라면 코치에게 앞 실습을 빠르게 대신 실행해 달라고 하는 편이 낫습니다.

| 파일 | 놓친 실습 | 복사할 곳 |
|---|---|---|
| 제품요약.md | 4 첫 업무 | my-agent 맨 위 |
| 고객의말.md | 6 컨텍스트 | my-agent 맨 위 |
| CLAUDE_예시.md | 7 규칙 한 장 | my-agent 맨 위에 CLAUDE.md 이름으로 |
| oneline-copy_SKILL_예시.md | 9 내 첫 스킬 | my-agent/.claude/skills/oneline-copy/SKILL.md 이름으로 |
| 경쟁조사.md | 12 서브에이전트 조사 | my-agent 맨 위 |

파일 이름에 '예시'를 붙여 둔 건, 이 폴더 안에서 진짜 규칙 · 스킬로 읽히지 않게 하려는 것입니다. 복사할 때 표의 이름으로 바꿉니다.
