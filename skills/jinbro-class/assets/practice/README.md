# 오전 실습 폴더 안내

클로드코드 입문 실습 폴더입니다. 수업 코치(`/jinbro-class`)를 처음 불렀을 때 이 폴더에 실습 자료가 깔렸습니다.
리부팅랩 × jinbro 오프라인 실습반 (2026-11-01)

## 들어 있는 것
```
my-agent/
├─ 자료/
│  ├─ 아침결_소개서.md      예시 제품 소개서 (가상 브랜드 '아침결 그래놀라')
│  ├─ 고객후기.md           예시 고객 후기 12개
│  └─ 고객인터뷰.md         예시 고객 인터뷰 3명 (긴 글 · 컨텍스트 실습용)
├─ 프롬프트팩.md           오늘 실습 문장 모음 (번호 = 화면의 '실습 N' 배지)
├─ 실습안내.md             지금 이 파일
├─ 수업코치/jinbro-class/  수업 코치 사본. 코치가 안내 파일을 여기서 읽으니 지우지 마세요
└─ .claude/settings.json    웹 검색 허용 설정
```
- 내 제품 자료가 없으면 예시 제품 '아침결 그래놀라' 자료로 그대로 따라 하면 됩니다
- 내 자료가 있으면 `자료` 폴더에 넣고, 실습 문장의 `아침결_소개서.md` 자리에 내 파일 이름을 넣습니다
- `.claude` 폴더는 숨겨져 보일 수 있습니다. 맥은 `Cmd + Shift + .`, 윈도우 탐색기는 보기 → 숨긴 항목
- 막히면 언제든 `/jinbro-class`, 번호를 붙이면 그 실습부터: `/jinbro-class 6`
